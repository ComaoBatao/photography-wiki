# Getting Started

This section takes Photography from “installed mod” to a working media item and cutscene.

Photography creates its own media directory under the Minecraft game directory:

```text
.minecraft/
└── mods/
    └── photography/
        ├── image/
        ├── audio/
        ├── video/
        └── subtitles/
            └── example_subtitles.json
```

The example subtitle file is created **only when missing**. Photography does not overwrite your edited copy later.

Continue with [Installation](installation.md), then [Quick Start](quick-start.md).
