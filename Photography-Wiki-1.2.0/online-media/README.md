# Online Media

Photography accepts valid HTTP/HTTPS sources for its media systems.

For video, WATERMeDIA remains responsible for the actual online video resolution/playback.

Confirmed Photography 1.2.0 workflows include:

- direct/normal HTTP(S) media sources
- Twitch through WATERMeDIA core
- YouTube through the optional WATERMeDIA YouTube Extension

Online video item screens also perform independent best-effort metadata lookup. Metadata never decides whether playback succeeds.
